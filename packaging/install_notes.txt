Close Creative Destruction before applying graphics settings.

This installer installs the control app. Open it, select client.exe, click Install / update, choose a preset and click Apply. Then start the game normally.

Python is included. No terminal commands or separate Python installation are needed.

Use Restore original in sg0hann Boost before uninstalling the control app. Uninstalling the control app alone does not remove the graphics helper from your game folder.

The graphics helper is for a permitted 32-bit Direct3D 9 client. Potato Graphics can blur UI and characters. Gray/black sky and No grass + flat ground require recognized shader metadata; some clients may retain original shaders. FPS gains are hardware dependent and are not guaranteed. The executable is unsigned.
