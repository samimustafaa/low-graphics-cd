# Texture Lab

Lower graphics for Creative Destruction, made for low-end PCs and laptops.

## What it does

- Four presets: Normal, Low, Ultra, and Potato Graphics.
- Separate sky choices: Normal (blue), Sky Gray, and Sky Black.
- Optional grass removal and flat ground in Potato Graphics.
- Shows which preset you applied.
- Checks for updates and can stay in the system tray.

## Getting started

1. Install the app and close the game.
2. Select your game's `client.exe`.
3. Click **Install / update** to add the graphics helper.
4. Choose your preset and options, then click **Apply preset**.
5. Launch the game and try it out.

**Close the game before changing settings.** After an app update, click **Install / update** again to update the game helper too.

To undo the changes, close the game and click **Restore original** before uninstalling Texture Lab. Right-click the tray icon and choose **Exit** to fully close the app.

## A few things to know

Requires Windows 10/11 and the 32-bit Direct3D 9 game client. Python is included.

Results depend on your PC and game client. Some textures or sky effects may stay unchanged, and an FPS boost isn't guaranteed. If something goes wrong, use **Diagnostics** to save a report.
