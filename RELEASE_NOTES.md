# Texture Lab 1.2.1

- Compact two-column layout: game connection on the left, texture controls on the right. Apply and status stay visible without page scrolling.
- Smaller typography and spacing, black backgrounds, dark preset selection and switches. Removed the native white scrollbar and lavender fills.
- Rounded dark buttons with short hover/press fades and a visible keyboard focus outline. Enter/Space activation is supported.
- Dark Windows title bar on supported systems; window sizing follows display scaling and screen size.
- Tray behavior, verified updates and the 1.2.0 graphics renderer are retained. No new texture/FPS claims are made in this interface-only release.

If you have 1.2.0, open **About → Check for updates** to install this release, or accept the update popup on opening. The app closes and reopens. Existing game-helper files do not need reinstalling for this interface update.

New users can use **TextureLab-Setup-1.2.1.exe** or the portable **TextureLab-1.2.1.exe**. Python is included and no console is required. Close the game before changing graphics presets.
